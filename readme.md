## 2025-12-06 Chapter 6 완료
 - 군집 알고리즘 : 그룹 클러스터로 데이터를 묶는 비지도 학습

## 2025-12-28 Chapter 7 완료
 - 인공 신경망 : 생체 뉴런에서 착안하여 가중치와 입력을 곱해 출력을 만드는 모델로
   - 입력층(Neuran)에서 출력층(최종 값)으로 데이터가 전달됨
 - 심층 신경망(DNN) : 2개 이상의 층을 가진 인공 신경망
   - 은닉층(Hidden Layer) : 입력층과 출력층 사이에 있는 모든 층으로, 활성화 함수가 존재하여 신경망의 성능을 향상시킴
   - Dropout : 훈련 과정에서 층에 있는 일부 뉴런을 랜덤하게 꺼서 과대적합을 막는 기법
   - Callback: 훈련 과정 중간에 Early Stopping나 모델 저장 같은 작업을 자동으로 수행할 수 있게 함
